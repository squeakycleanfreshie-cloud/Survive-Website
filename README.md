# Survive — Hack Club YSWS Landing Page

A landing page for **Survive**, a Hack Club "You Ship We Ship" program where teens aged 13-18 build survival and offline-themed products to earn camping gear and event tickets.

## What is this?

Survive is a build-to-earn challenge for Hack Club members. Participants build real survival or offline-themed tools/devices, submit them for review, and earn "wood" currency to spend in the shop on outdoor gear or an event ticket.

## Features

- Full screen pixel art splash with animated ENLIST NOW button
- "What is this event?" section
- Collapsible FAQ
- How it works 
- Infinite scrolling prize carousel
- Footer
